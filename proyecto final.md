## Definiciones y ejemplos

### 1. Algoritmo
**Definición:** Conjunto ordenado y finito de pasos que permite resolver un problema o realizar una tarea.
**Ejemplo:** Para preparar café: calentar agua, colocar café en la taza, agregar el agua y mezclar.

### 2. Programa
**Definición:** Conjunto de instrucciones que una computadora puede ejecutar para cumplir una función determinada.
**Ejemplo:** Una calculadora es un programa que recibe números y operaciones, y muestra el resultado.

### 3. Código fuente
**Definición:** Texto con las instrucciones escritas por el programador en un lenguaje de programación.
**Ejemplo:** `console.log("Hola, mundo");` es una línea de código fuente en JavaScript.

### 4. Lenguaje de programación
**Definición:** Sistema de reglas, símbolos y palabras reservadas que permite escribir instrucciones para una computadora.
**Ejemplo:** Python, JavaScript, Java y C++ son lenguajes de programación.

### 5. Sintaxis
**Definición:** Reglas que indican cómo deben escribirse correctamente las instrucciones de un lenguaje.
**Ejemplo:** En JavaScript, una función puede escribirse como `function saludar() { }`; omitir una llave puede producir un error de sintaxis.

### 6. Variable
**Definición:** Espacio identificado en la memoria que almacena un dato cuyo valor puede cambiar durante la ejecución.
**Ejemplo:** `let edad = 18;` y después `edad = 19;` muestran que el valor de la variable puede cambiar.

### 7. Constante
**Definición:** Dato asociado a un nombre cuyo valor no debe modificarse durante la ejecución del programa.
**Ejemplo:** `const PI = 3.1416;` define un valor que no debería cambiar.

### 8. Tipo de dato
**Definición:** Clasificación que indica qué clase de valor almacena una variable y qué operaciones pueden realizarse con él.
**Ejemplo:** `"Ana"` es una cadena de texto, `20` es un número y `true` es un valor booleano.

### 9. Operador
**Definición:** Símbolo o palabra que permite realizar una operación sobre uno o más valores.
**Ejemplo:** En `suma = 4 + 3`, el símbolo `+` es un operador aritmético.

### 10. Expresión
**Definición:** Combinación de valores, variables, operadores o funciones que se evalúa para producir un resultado.
**Ejemplo:** `precio * cantidad` es una expresión que calcula el costo de varios productos.

### 11. Condicional
**Definición:** Estructura de control que toma decisiones según se cumpla o no una condición.
**Ejemplo:** `if (edad >= 18) { console.log("Mayor de edad"); }` muestra un mensaje solo cuando la condición es verdadera.

### 12. Bucle
**Definición:** Estructura que repite un conjunto de instrucciones mientras se cumpla una condición o durante un número determinado de veces.
**Ejemplo:** `for (let i = 1; i <= 5; i++)` puede repetir una acción cinco veces.

### 13. Función
**Definición:** Bloque de código reutilizable que realiza una tarea específica y puede recibir datos o devolver un resultado.
**Ejemplo:** `function saludar() { console.log("Hola"); }` define una función para mostrar un saludo.

### 14. Parámetro
**Definición:** Variable incluida en la definición de una función para representar un dato que esta espera recibir.
**Ejemplo:** En `function duplicar(numero)`, `numero` es el parámetro.

### 15. Argumento
**Definición:** Valor concreto que se entrega a una función cuando se realiza una llamada.
**Ejemplo:** En `duplicar(5)`, el valor `5` es el argumento enviado al parámetro `numero`.

### 16. Retorno
**Definición:** Valor que una función devuelve al terminar su ejecución mediante una instrucción de retorno.
**Ejemplo:** `return a + b;` devuelve la suma calculada por una función.

### 17. Arreglo
**Definición:** Estructura de datos que almacena varios elementos en una misma variable y permite acceder a ellos mediante índices.
**Ejemplo:** `let frutas = ["manzana", "pera", "uva"];`; `frutas[0]` devuelve `"manzana"`.

### 18. Objeto
**Definición:** Estructura que agrupa datos y comportamientos relacionados mediante propiedades y métodos.
**Ejemplo:** `{ nombre: "Luis", edad: 20 }` es un objeto con las propiedades `nombre` y `edad`.

### 19. Método
**Definición:** Función asociada a un objeto que define una acción que ese objeto puede realizar.
**Ejemplo:** `texto.toUpperCase()` es un método que convierte un texto a mayúsculas.

### 20. Evento
**Definición:** Acción o situación detectada por un programa que puede activar una respuesta.
**Ejemplo:** El evento `click` se produce cuando una persona presiona un botón de una página web.

### 21. Compilador
**Definición:** Programa que traduce el código fuente a otro lenguaje o a código ejecutable antes de ejecutar el programa.
**Ejemplo:** El compilador de C++ transforma un archivo `.cpp` en un programa ejecutable.

### 22. Intérprete
**Definición:** Programa que analiza y ejecuta instrucciones de código fuente durante la ejecución, generalmente paso a paso.
**Ejemplo:** El intérprete de Python ejecuta instrucciones de un archivo `.py` sin que el usuario tenga que compilarlo manualmente.

### 23. Depurador (Debugger)
**Definición:** Herramienta que permite ejecutar un programa de forma controlada para encontrar y corregir errores.
**Ejemplo:** Se coloca un punto de interrupción en una línea para revisar el valor de una variable antes de que continúe el programa.

### 24. IDE
**Definición:** Entorno de Desarrollo Integrado que reúne editor de código, herramientas de ejecución, depuración y administración de proyectos.
**Ejemplo:** Visual Studio Code, IntelliJ IDEA y PyCharm pueden utilizarse como entornos de desarrollo.

### 25. Editor de código
**Definición:** Aplicación especializada para escribir y modificar código fuente, normalmente con ayudas visuales y de edición.
**Ejemplo:** Visual Studio Code permite editar archivos `.js`, resaltar su sintaxis y buscar texto en el proyecto.

### 26. Biblioteca (Library)
**Definición:** Colección reutilizable de código que ofrece funciones, clases o módulos para resolver tareas comunes.
**Ejemplo:** La biblioteca `Math` de JavaScript permite usar `Math.round()` para redondear números.

### 27. Framework
**Definición:** Conjunto estructurado de herramientas, reglas y componentes que sirve como base para construir aplicaciones.
**Ejemplo:** React puede utilizarse como framework o biblioteca de interfaz para crear componentes de una aplicación web.

### 28. API
**Definición:** Interfaz que define funciones, reglas y formatos para que un programa se comunique con otro software o servicio.
**Ejemplo:** Una aplicación del clima puede usar una API para solicitar la temperatura actual a un servidor.

### 29. Repositorio
**Definición:** Espacio donde se almacenan los archivos de un proyecto junto con información sobre sus cambios y versiones.
**Ejemplo:** Una carpeta local con el código de una página y su historial de Git es un repositorio.

### 30. Control de versiones
**Definición:** Sistema que registra los cambios de los archivos y permite consultar el historial, comparar versiones o recuperar estados anteriores.
**Ejemplo:** Si una modificación rompe el programa, el equipo puede volver a una versión anterior.

### 31. Git
**Definición:** Sistema distribuido de control de versiones que permite registrar cambios, crear ramas y administrar proyectos.
**Ejemplo:** `git add .`, `git commit -m "Primera versión"` y `git push` son comandos habituales de Git.

### 32. GitHub
**Definición:** Plataforma en línea que aloja repositorios Git y ofrece herramientas para colaborar y compartir código.
**Ejemplo:** Un estudiante puede publicar su README en GitHub para que el docente lo consulte mediante un enlace.

### 33. Rama (Branch)
**Definición:** Línea independiente de desarrollo dentro de un repositorio que permite trabajar sin modificar directamente la rama principal.
**Ejemplo:** `git branch nueva-funcion` crea una rama para desarrollar una función nueva.

### 34. Commit
**Definición:** Registro de un conjunto de cambios dentro de un repositorio Git, acompañado normalmente por un mensaje descriptivo.
**Ejemplo:** `git commit -m "Agrega ejemplos al glosario"` guarda los cambios con una explicación.

### 35. Merge
**Definición:** Operación que integra los cambios de una rama con otra.
**Ejemplo:** Después de terminar una función, se puede hacer merge de `nueva-funcion` hacia `main`.

### 36. Callback
**Definición:** Función que se entrega como argumento a otra función para ejecutarse posteriormente, por ejemplo al terminar una operación.
**Ejemplo:** `setTimeout(() => console.log("Listo"), 1000);` usa una función callback que se ejecuta después de un segundo.

### 37. Programación síncrona
**Definición:** Forma de ejecución en la que las instrucciones se procesan en orden y una operación debe terminar antes de iniciar la siguiente.
**Ejemplo:** En una suma sencilla, el programa calcula primero el resultado y después muestra el mensaje.

### 38. Programación asíncrona
**Definición:** Forma de ejecución que permite iniciar una operación que tarda cierto tiempo sin bloquear necesariamente el resto del programa.
**Ejemplo:** Una página puede solicitar datos a un servidor y seguir respondiendo mientras espera la respuesta.

### 39. JavaScript
**Definición:** Lenguaje de programación usado principalmente para agregar comportamiento e interactividad a páginas web; también puede utilizarse en servidores.
**Ejemplo:** Un script de JavaScript puede validar un formulario antes de enviarlo.

### 40. TypeScript
**Definición:** Lenguaje basado en JavaScript que añade tipos estáticos, interfaces y herramientas de verificación; normalmente se transforma a JavaScript.
**Ejemplo:** `function sumar(a: number, b: number): number { return a + b; }` indica que los parámetros y el resultado son números.
